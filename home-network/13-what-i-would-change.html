What I Would Change

A few things stand out looking back at the whole project, not as regrets exactly, more as places where I'd approach it differently if I were starting over today with everything I know now.

I'd close the DNS bypass earlier

The ER605's DHCP setup hands out Pi-hole as the primary DNS server for every VLAN, with a public resolver like Cloudflare's 1.1.1.1 set as a secondary. That secondary exists purely for redundancy, so a device isn't left with no DNS at all if Pi-hole ever goes down for maintenance or crashes unexpectedly. But it also means a device is technically free to just use that secondary resolver directly and skip Pi-hole's filtering entirely, whether by design or by accident on the device's part, and I never actually closed that gap with a firewall rule forcing all DNS traffic through Pi-hole specifically. It's a minor issue day to day, since most devices just use whatever resolver comes first in the list, but it's a loose end I noticed and never tied off. If I were doing this again I'd handle it up front with an explicit rule, instead of leaving it as a known gap I have to remember exists.

I'd test cross-VLAN application behavior before calling a feature done

Both the mDNS problem and the Plex subnet bug followed the exact same shape. The network-level work looked complete, the firewall rules were in place and correct, and then a specific application turned out to have its own separate assumptions about what counts as reachable or local that had nothing to do with my router. Next time, once basic routing and firewall rules are in place for something like casting or media streaming, I'd deliberately test it from every VLAN it actually needs to work from before considering that feature finished, instead of finding out weeks later that "it works" only ever meant it worked from the one network I happened to test it from first.

I'd document decisions as I made them

Reconstructing this project after the fact, from scattered notes and half-remembered configuration changes, made it obvious how much easier this whole process would have been with a running notes file kept alongside the actual work. A short line for every VLAN rule I added, why it exists, and what specific problem it solves, would have saved a lot of the archaeology that went into pulling this project back together into something coherent enough to actually explain to someone else.

What I wouldn't change

The decision to keep the AT&T gateway around instead of replacing it outright, to skip buying a dedicated Plex server, and to avoid exposing my home network to the internet just to self-host a couple of small side projects, all still feel right to me. Not every part of a home network needs to be maximally self-hosted or maximally custom to be worth building. Some of the better decisions in this whole project were the ones where I deliberately chose not to add more.
