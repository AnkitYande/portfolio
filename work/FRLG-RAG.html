Pokémon FRLG — RAG Powered AI Guide

Spring 2026

RAG Pipeline Python / Flask ChromaDB Gemini 2.5 Flash Web Scraping BeautifulSoup Vector Search HTML / CSS / JS

Pokémon FRLG RAG Guide is a full-stack AI assistant that answers natural language questions about Pokémon FireRed and LeafGreen — where to find Pokémon, how to beat Gym Leaders, item locations, and more. Responses are grounded in real game data and delivered in character as Professor Oak, making it both technically rigorous and genuinely fun to use.

The core of the project is a custom RAG (Retrieval-Augmented Generation) pipeline built from scratch. Rather than relying on a pre-existing dataset, custom scrapers were written for two sources with completely different structures: Bulbapedia via the MediaWiki render API and Serebii via BeautifulSoup HTML parsing. A deliberate chunking strategy splits each page into semantically focused chunks — one per table type (trainers, encounters, items) and one for prose — with source metadata prepended into the chunk text before embedding. This ensures the vector encodes location context alongside content, dramatically improving retrieval precision.

Chunks are embedded using Google's Gemini Embedding API and stored in ChromaDB with a tuned HNSW index to ensure consistent nearest-neighbor quality regardless of result count. At query time, the user's question is embedded with the same model, the top matching chunks are retrieved, and injected as context into a Gemini 2.5 Flash prompt that constrains the model to answer only from the retrieved data — preventing hallucination.

The frontend is a static site deployed on GitHub Pages, communicating with a Flask API on Render. A debug mode lets users inspect exactly which chunks the AI used to form its answer, including similarity scores and links back to the original sources.
