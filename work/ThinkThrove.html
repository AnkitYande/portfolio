ThinkTrove

Spring 2025

React / Vite Node.js / Express Groq LLaMA 3.3 REST API AI Prompt Engineering

ThinkTrove is an experimental educational AI platform that empowers teachers to design structured, inquiry-based lessons and helps students develop deeper reasoning skills through guided dialogue with an adaptive AI tutor. It was built to explore how artificial intelligence can enhance—not replace—the human process of learning and reflection.

The platform consists of two interfaces: a Teacher Dashboard for lesson creation and a Student Chat Interface for interactive learning. Teachers can define valid hypotheses, misconceptions, learning phases, and tone settings, which are then used by the backend to dynamically generate structured AI prompts. Students engage in an immersive chat environment where the AI adapts to their reasoning style and offers hints, not answers—mimicking a true Socratic tutor.

Built using a React + Vite frontend and an Express backend, ThinkTrove integrates with Groq’s LLaMA 3.3 model for ultra-fast and context-aware responses. The backend features RESTful endpoints for managing configurations and chats, with intelligent conversation summarization to reduce token usage while maintaining context. The UI emphasizes reusability, responsiveness, and clean modular design for scalability and classroom adaptability.

In an era where information and AI-generated answers are abundant, critical thinking has become the most essential skill a learner can cultivate. ThinkTrove bridges pedagogy and technology to foster that skill—transforming education from passive information intake into active inquiry. It aims to make learning more interactive, reflective, and human-centered in the age of automation.
